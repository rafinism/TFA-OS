## Important existing work

The Player Pool UI should be treated as existing work to integrate, not automatically replace. The Constitution page/presentation should likewise be preserved unless a concrete defect or approved requirement requires change.

## Completion definition

A feature is not complete merely because a page renders. For business features, completion requires appropriate database persistence, backend validation, authorization, UI state handling, audit/history where required, and tests.
