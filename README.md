# TFA Football Simulator

A football club-management simulation platform built for the TESL Football Association.

## Vision

TFA Football Simulator allows members to experience the role of a football club manager.

Managers can:

- Manage their club
- Build and manage their squad
- Sign and renew players
- Manage TCP finances
- Play competitions
- Submit match results
- Track club performance
- Build club history

The system is governed by the TFA Constitution.
